# Skill: 出典フォーマット (citation_format)

藤沢市の情報を提供する全エージェント (info-bot / 保活) で **必ず** 出典 URL を応答に
含める。引用なしの回答は再生成する。

## 必須要素

応答には以下を含める:

1. **回答本文**: 簡潔に、1 段落〜数段落
2. **出典 URL**: 該当する元ページを必ずリンクとして提示。複数ページ参照した場合は
   主要なものを優先 (3 件まで)
3. **最終確認日**: ETL の `as_of` (取得日時) から `freshness_disclaimer` Skill のルールで導出
4. **免責**: 「最新情報は公式 HP でご確認ください」

## フォーマット例 (LINE 表示)

```
鵠沼地区のゴミ収集は、燃えるゴミが月・木、プラ容器が水曜です。

🔗 出典: https://www.city.fujisawa.kanagawa.jp/.../gomi.html
📅 最終確認: 2026-05-01 (8 日前のデータ)
※ 最新情報は公式 HP でご確認ください。
```

## 違反検知ルール

- `source_url` が空の場合: 「お答えできません、公式 HP をご確認ください」へフォールバック
- 複数の事実情報を提示する場合: 各事実ごとに出典を区別 (1 つの URL でまとめないこと)
- 推測・憶測表現 ("〜だと思われます" 等) は使わない、出典に書かれていない情報は提示しない

## consumer 別の補足

- **info-bot**: カテゴリ別に出典フォーマット同じ。緊急情報の場合は冒頭に "[緊急]" 接頭辞
- **保活**: Score-Calc / Cost-Calc の根拠説明では「申込ナビ R8 年度版 P.XX」を併記
