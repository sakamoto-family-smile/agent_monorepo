# Skill: LINE 出力フォーマット (line_output_format)

LINE Messaging API の制約に合わせた応答整形ルール。

## 文字数制約

- **テキストメッセージ**: 1 通 5,000 文字以内、ただし **可読性のため 600 文字以内** を推奨
- **Flex Message**: bubble 1 つで 50 KB 以内、Carousel は 12 bubble まで

## 改行ルール

- **1 行 30 文字以内** (スマホ縦持ち時の折返しを考慮)
- 段落間に空行 1 つ
- リスト形式は `- ` または `1. ` で開始

## 絵文字ガイド

過剰な装飾は避ける。意味を持たせる:

| 絵文字 | 用途 |
|---|---|
| 🔗 | 外部 URL リンク |
| 📅 | 日付・期日 |
| 📞 | 電話番号 |
| ⚠️ | 注意・警告 (鮮度警告等) |
| 🏫 | 保育施設・学校 |
| 🏠 | 自宅・住所 |
| 💰 | コスト・料金 |
| 📊 | データ・統計 |
| ✅ | 完了・OK |
| ❌ | NG・該当しない |

## URL 表示

- LINE ではテキスト中の URL が自動的にプレビューカードになる場合がある
- 重要な URL は単独の行に置く (前後に空行)
- 短縮 URL は使わない (信頼性低下)

## Flex Message のユースケース

以下の場合のみ Flex Message を使う:

- 比較表 (複数園のスペック比較)
- ボタン UI (「タスク完了」「プラン保存」)
- カテゴリ選択 (info-bot のリッチメニュー連携)
- カルーセル (希望順位リスト等)

それ以外は標準テキストで十分 (実装コストを抑える)。

## consumer 別の補足

### info-bot
- 緊急情報 push は冒頭に `[緊急]` を必ず付ける
- カテゴリ別アイコン (防災=⚠️ / 子育て=🍼 / ゴミ=🗑️ 等) を冒頭に

### 保活
- 月コスト試算は表形式 (Flex Carousel 推奨)
- 保活プランは Flex Carousel で各希望園 1 bubble
- スケジュールは Flex の vertical layout でタスクリスト

## 違反検知ルール

- 1 メッセージが 2,000 文字を超えたら警告 (LLM に再生成を依頼)
- URL に短縮 URL (`bit.ly`, `t.co` 等) が含まれたら拒否
- 制御文字 (改行以外) を弾く
