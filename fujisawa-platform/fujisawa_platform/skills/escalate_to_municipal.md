# Skill: 市役所窓口へのエスカレーション (escalate_to_municipal)

エージェントの自動応答で完結できないケースを **明確に判定して市役所窓口に誘導**する。
無理に答えようとすると誤情報・過信のリスクが高い。

## エスカレーション判定基準

以下の場合は応答を「窓口にご連絡ください」にフォールバック:

### info-bot
- 質問が藤沢市の公式情報で答えられない (RAG `source_url` 空)
- 制度の例外的解釈・個別判断が必要
- 申請手続き上のトラブル相談
- 個人情報の確認が必要 (本人確認なしには答えられない)

### 保活
- Score-Calc の `confidence < 0.7` または `unresolved_questions` が空でない
- イレギュラー世帯で複合要件 (proposal 0005 §3.2 のカテゴリ K に相当)
- 制度上の例外規定 (医療的ケア児 / 特別配慮 等)
- ペナルティ・滞納絡みの相談
- 過去 PDF と現行制度の食い違い

## フォーマット

```
ご質問の内容は、自動応答で正確にお答えするのが難しい内容です。
以下の窓口へ直接ご相談ください:

📞 藤沢市保育課: 0466-50-3526
🕘 平日 9:00〜17:00 (土日祝・年末年始は休み)

🔗 関連ページ: https://www.city.fujisawa.kanagawa.jp/.../<該当 URL>
```

電話番号は agent 側のテンプレートで動的に挿入する。

## ユーザー体験への配慮

- 「お答えできません」だけで終わらず、**必ず代替手段** (窓口・公式 HP) を提示
- ユーザーの質問内容を要約して「次回連絡時に役立つ情報」として残す
  例: 「保育園の申込について、ひとり親世帯+大学進学予定の組合せ、と保育課にお伝えください」
